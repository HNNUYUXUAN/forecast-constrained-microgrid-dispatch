# 公开副本边界

创建日期：2026-09-14。

本目录是从私有竞赛工作区按允许列表抽取的独立副本，目的不是清洗旧仓库后直接改为公开，而是从源头避免旧历史、第三方二进制和运行归档进入公开仓库。

## 已包含

- `c_grid/src/`：原创建模、数据读取、滚动调度和结算代码；
- `scripts/`：计算、验证、导出、输入校验和发布门禁；
- `tests/`：合成单元测试与可选官方数据集成测试；
- `data/INPUTS.sha256`：官方输入指纹，不含输入本体；
- `results/reference/`：精简场景汇总；
- `results/figures/`：由项目代码从参考运行生成的图。

## 明确排除

- 私有仓库 `.git` 历史及其应用内部引用；
- `archive/`、`deliverables/`、`outputs/`、`notebooks/`；
- 题面、附件、格式模板、论文全文、支撑包、远端取回材料；
- PDF、DOC/DOCX、XLS/XLSX、ZIP/RAR/7Z、CAJ、可执行文件；
- `.env`、凭据、远端地址、个人机器路径和缓存。

公开副本是一个新的 Git 根目录。不要把原私有远端直接改为 public，也不要把旧历史合并进来。
